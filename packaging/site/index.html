What you need

A C toolchain, and nothing else

The download carries the rustc it was built with and the vieww libraries it was linked against, so you do not need Rust installed — the preview compiles against exactly this build, by construction.

What it cannot carry is a linker. A preview is a shared library, and rustc links it through cc: install build-essential on Linux, the Xcode Command Line Tools on macOS, or the MSVC Build Tools on Windows.

Install

# Debian, Ubuntu — apt pulls in the C toolchain for you
curl -LO https://github.com/__REPO__/releases/latest/download/viewwstudio-linux-x86_64.deb
sudo apt install ./viewwstudio-linux-x86_64.deb

# anything else: one file, no install step
curl -LO https://github.com/__REPO__/releases/latest/download/viewwstudio-linux-x86_64.AppImage
chmod +x viewwstudio-linux-x86_64.AppImage && ./viewwstudio-linux-x86_64.AppImage
# open the .dmg and drag vieww Studio to Applications, then:
xcode-select --install          # the linker, once per machine

# unsigned, so the first launch needs a right-click → Open,
# or, if Gatekeeper has already quarantined it:
xattr -dr com.apple.quarantine "/Applications/vieww Studio.app"
# run the .msi, then install the linker once:
winget install Microsoft.VisualStudio.2022.BuildTools ^
  --override "--quiet --add Microsoft.VisualStudio.Workload.VCTools"
